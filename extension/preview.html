Install the developer build

Four steps, no store listing yet.

  1. 01Open chrome://extensions in Chrome 116 or newer.
  2. 02Switch on Developer mode (top right).
  3. 03Click Load unpacked.
  4. 04Select the Tudumm-AI-engine/extension folder, then pin the two-beat icon.

Permissions requested: storage, sidePanel, activeTab, and host access to the Tudumm site only (live data and account linking). Access to localhost is optional and asked only when you point Options at a local dev API. The chip runs only on the eight supported sites.

Tudumm is in beta. Live data is labelled with its source and freshness, and live signals come from engine v0, which is uncalibrated. Signals are probabilistic and not investment advice. Trading involves risk of loss.
